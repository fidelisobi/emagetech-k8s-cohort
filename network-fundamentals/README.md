# 🌐 Network Fundamentals

Welcome! This folder is for **complete beginners** — no networking experience required.

By the end of these tutorials, you'll understand how the internet works and how computers talk to each other. This knowledge is foundational for Kubernetes, where networking is everywhere.

## 🎯 How to Use These

Read them in order. Each one builds on the last.
Don't skip around — the concepts stack on each other.

**Estimated time:** ~2–3 hours total, reading + practice

## 🔗 Why This Matters for Kubernetes

Kubernetes is basically a network of containers. Every Pod has an IP address.
Services route traffic between Pods. Ingress controls what gets in from outside.
**None of that makes sense without knowing networking first.**
