# 🐙 Git Fundamentals

Welcome! This folder is for **complete beginners** — no Git or version control experience needed.

Git is the tool that every software team on the planet uses to track code changes and collaborate. Kubernetes itself lives in a Git repo. So does this class.

## 🔗 Why This Matters for Kubernetes

Everything in Kubernetes is defined as YAML files. Those YAML files live in Git.
The modern way to manage Kubernetes is **GitOps** — Git is the source of truth for what your cluster should look like.

You can't do GitOps without understanding Git.
